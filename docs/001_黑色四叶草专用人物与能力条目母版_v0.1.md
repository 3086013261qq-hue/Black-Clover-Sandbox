借鉴既有工程已核对格式：

人物条目负责身份、所属、魔导书**概况**、外貌、人格与关系。能力条目负责法术原理、魔导书与招式**细节**、武器、消耗、局限和战斗方式。两条共同触发，避免正文大量重复。

**沿用原有**：名字 / 性别 / 印象 / 发色 / 发型 / 瞳色 / 身材 / 胸部 / 上衣 / 下装 / 配饰 / 鞋子 / 心理模型四槽 / 三句中文对话范例。

**增补字段**（位于印象之前，以便身份一眼可读）：
- `年龄`：仅在可靠资料中有依据时填具体年龄，未知不可硬编。
- `种族`：人类、精灵、恶魔等依各人物资料核实；不可一概默认。
- `出身国家`：对应王国/日之国等；出身不同于当前效忠。
- `身份与职位`：魔法骑士团团长、王族、职务或阶段性位阶，避免把时间线后期成就写成开局恒定状态。
- `所属组织`：填写魔法骑士团及其他稳定所属组织；多重/历史组织要标明阶段，不能把王国、骑士团、个人身份混为同一层。
- `魔法属性`：简记已证实的魔法属性，**不是技能清单**；无魔力、双属性、恶魔力量等依事实区别表述。
- `魔导书`：记录所属国徽记/封面特征、四叶草王国的叶数、一本或多本及特殊情况；不抄写全部法术，详见能力条目。

## 三、特殊情况

1. 魔导书的国家徽记不能统一写成「三叶草/四叶草」。草、钻、心、黑桃各国的魔导书封面徽记不同。只有明确属于草之国魔导书的才按叶数核对。
2. 多本魔导书：允许逐本概述，例如由诺有不同国别的两本魔导书，不能粗暴合并。
3. 无魔导书者：如尚未领取、使用卷轴的日之国人物、特定非人类角色，写「无 / 不适用 / 卷轴」并说明已知事实，不硬编一本。
4. 特殊书籍与能力：阿斯塔无魔力，拥有五叶草魔导书和反魔法；**不得**写成普通「黑暗魔法属性」。
5. 形态、晋升、所属、魔导书获得、特殊力量觉醒是时间变化：人物条目以指定叙事基线为准，不提前赋予；时间线记录获得日期/事件；能力层说明使用条件。
6. 原著未提供体重或罩杯时，必须在工程来源记录中标记「未公布」。若为兼容卡包而采用推定身材数值，明确区分卡内工作值和官方设定，绝不冒称官方。
7. 人物印象与心理模型使用真实行为依据，不把分析性推断写成作品内医学诊断。
8. 正式人物正文用内世界中文表述，不残留 Wiki、原著、工程、卡包、推定值、原卡等施工说明；证据与工作说明只保留在旁侧审计资料。

## 四、配套能力条目

```text

能力定位:

代表法术:

```

能力子栏目是便于撰写的候选组织方式，不强加任何原著没有的属性/武器。与人物条目保持相同角色名和同源关键词；V3 中的精确触发参数另按咩咩原规范核验。
