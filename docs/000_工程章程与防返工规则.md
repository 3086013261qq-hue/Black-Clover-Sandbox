# 000｜《黑色四叶草》工程章程与防返工规则

状态：INITIALIZED / 非封版
日期：2026-11-12
唯一仓库：3086013261qq-hue/Black-Clover-Sandbox
分支：main

## 范围
- 原作漫画全篇的世界设定、正式人物、能力、时间线、地点。
- 以 Black Clover Wiki 的目录和逐话摘要建立可追踪的资料索引；重要事实与原著相互核对。
- 外传、动画原创、游戏内容先隔离，不擅自视为漫画正史。
- 玩家原创人物在独立设计阶段处理，不与原作人物/能力总目录混淆。

## 生产顺序及锁定
1. 资料索引与篇章覆盖检查，先排漏。
2. 设定：蓝灯骨架—>对应绿灯，标明依赖、关键词和触发设计。
3. 人物：完整人物目录，外观/出场/关系/职业/组织/状态；不得把未经查证的细节当官方。
4. 能力：人物能力、魔法属性、魔导书、装备、觉醒与状态的关联核对。
5. 时间线：逐篇章逐事件构建；分卷以故事连续性为准；先建立剧情顺序，再建立有证据的日历锚点。
6. 地点：按国家、区域、具体地点与人物活动范围检查漏项。
7. QA和封版：先核对一层再冻结；构建与装卡只能使用封版正文。

## 硬规则
- 用内世界叙述撰写正式世界书条目，不把工程注释写入扮演文本。
- 时间线保留原题；事件采用卷内 A/B/C 顺序，连续事件按故事实际日程推进；未知年月日只能先标「待考据」，不能伪造。
- 人物与能力独立，人物关键词包含适当的别名；男性/女性外观信息按已有卡包规格核验，官方缺失者在资料记录里留证据缺口，勿冒充官方身材参数。
- 原著角色/魔法/装备命名必须比对原资料；存在中文译名分歧时建立统一中文名表。
- 不修改已经封版的条目；发现错误先立审计记录，确认范围后修。
- 先读取实际「咩咩制卡包·全栈」格式及其零件要求，再装配正则、状态栏、脚本、开放话题池、防递归、时间线开关等；禁止凭印象自拟格式。
- 不使用不经授权的整段 Wiki/漫画文本复制。资料索引保留链接、来源和自撰摘要。
- 未经单独确认，不把原创玩家角色写进原著全栈人物表。

## 首轮待办
- 核对 Wiki 目录是否覆盖至最终第392话。
- 为各篇章逐话建立「章节—登场人物—事件—能力—地点」索引。
- 核实四国、魔法组织、魔导书/魔法体系等设定层目录。
- 收集全栈规范、历史可复用卡包模板后再写首条正式蓝灯。
