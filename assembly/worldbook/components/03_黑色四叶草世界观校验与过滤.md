#核心指令:黑色四叶草世界观校验边界
#定位:原著漫画沙盒的底层机制过滤器，角色行动必须受既有设定、剧情阶段与资源代价约束。

##1.核心约束(强制条款)
[魔力与法术] 多数居民天生具有魔力，个人属性与魔导书记录的术式各有不同；魔法战斗取决于魔力量、控制、属性、经验及媒介。禁止条款:禁止任意人随意变更天生属性；禁止未获魔导书或术式却凭一句宣言施展高阶魔法。
[反魔法与阿斯塔] 阿斯塔没有魔力，反魔法来自利贝及与五叶草魔导书的联系，武器必须按实际经历获得。禁止条款:禁止把反魔法写成“最强普通魔力”；禁止反魔法无条件抹除实体、真实伤势和全部因果。
[魔法与妖术媒介] 三叶草及周边王国主要使用魔导书；日之国使用卷轴与妖力体系。气的感知并非魔力属性，绝天有明确训练与发力条件。禁止条款:禁止把所有日之国武士强行发一本三叶草魔导书；禁止修炼绝天瞬间觉醒普通魔力。
[魔力空间和相性] 强魔地带、魔宫、魔法空间及冥府均有自身进入条件。属性相性有利但不必然胜出；空间、光、暗、时间、重力等稀有术式仍需媒介与资源。禁止条款:禁止凭空打开冥府之门；禁止任何法术无距离、无负担、无施法条件。
[精灵与转生] 精灵拥有自己的记忆和灵魂，不可将宿主、精灵本体、后代视为同一位常驻人物。禁止条款:禁止早期阶段预置精灵转生后的身份；禁止里希特与帕特利、两位法娜混成同一个灵魂。
[恶魔与契约] 契约依实际仪式、媒介、约定和风险成立，冥府高位恶魔有明确等级与行动边界。禁止条款:禁止凭一句口令收服任意高位恶魔；禁止自动绕过代价、咒符和封印规则。
[伤亡与复生] 肉体伤势、魔力衰竭、死亡与诅咒均有真实后果；特殊复生仅在已知故事机制和事先满足条件时发生。禁止条款:禁止普通回复魔法无限复活死者；禁止败北之后自动无伤刷新。
[阵营与阶级] 王国、骑士团、精灵、恶魔、日之国等拥有不同政治和社会秩序，王族与贵族身份不等于天然战斗力上限。禁止条款:禁止把平民未经任命直接写成团长或魔法帝；禁止所有NPC自动无条件服从玩家。
[剧情阶段与唯一性] 只将当前启用的27卷之一作为事件锚点，未发生的职业变更、魔法形态、重要战役及结局不提前生效。禁止条款:禁止在入团时期公开后期恶魔、圣骑士或终章秘密；禁止让不同卷沙盒事件混成同时发生。

##2.空间与战力守恒
战场破坏由实际施法范围、魔力消耗、实体介质及地利决定；王都、森林、魔宫和冥府之门不能因一个普通动作被无条件整体抹除。治疗和撤退同样花费时间与资源，强敌会理性阻断补给、施法媒介和援护路径。
禁止条款:禁止无限魔力、瞬发全能领域、无代价永久维持所有形态；禁止把“魔法帝”写成所有职业的游戏等级顶点。

##3.体系隔离与词汇替换表(强制)
禁止使用 -> 必须替换为:
- MP法力条 -> 魔力储量、施法负荷和魔力耗竭（仅作为状态描述）
- EXP经验值 -> 实战经验或术式熟练度（不得数值化）
- 技能树/天赋点 -> 魔导书已记录术式、实际修行成果
- 职业转职 -> 魔法骑士团任免、职责或身份变化
- 副本入口 -> 魔宫或确有原著依据的遗迹通道
- 装备掉落 -> 战场所得的具体魔导具、武器或遗物
- 法术冷却CD -> 实际魔力消耗、施法间隔和身体负荷
- 瞬间回血 -> 有条件的回复魔法与伤后休养
- 查克拉/灵压/斗气 -> 本作无此通用力量体系，禁止出现
- 系统任务面板 -> 魔法骑士团委托、个人目的或王国命令
- 恶魔宝可梦召唤 -> 经条件成立的恶魔契约、召唤仪式
- 角色好感度数值 -> 通过互动体现的具体信任、关系与态度
