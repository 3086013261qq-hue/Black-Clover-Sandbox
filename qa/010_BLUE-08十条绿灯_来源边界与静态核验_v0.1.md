## 要点审计
- [x] 日之国隔海、语言与姓前名后次序独立于四大王国；并未设为三叶草附属地。
- [x] 将军统领国家；伍州、广州各有当地领主家族。将军不直接等同三叶草魔法帝，也不能仅凭妖力多少认定政治统治者。
- [x] 龙禅七人众为七名将军直属强者，能够运用绝天；不套用骑士团军阶，也不将个人风格一律相同化。
- [x] 妖力 = 当地的魔力称谓、妖术 = 当地的魔法称谓，非凭空发明新的自然属性；卷轴原理仅与 BLUE-03 交叉引用，避免重复完整规则。
- [x] 气是生命活动的流动，与魔分开但可相互影响；气的感知可帮助捕捉动作、情绪与目标位置，不等于全知读心。
- [x] 妖术/魔法施展时常无意识调动气，主动驾驭气可临时强化身体与妖力。
- [x] 绝天通过精确控制气，将体内力量集中并瞬发，威力受妖力储量与动作速度影响；能够分成多次攻击但每击会削弱。
- [x] 绝天既可手足发动，也可经刀剑斩击引出；阿斯塔使用反魔法是特殊先例，不将其写作普通所有人都拥有的额外妖力属性。
- [x] 日本式刀形和近身武艺确实存在，武道身法、妖术、气与绝天各有学习条件。
- [x] 伍州黑海及五头龙、天女封印是当地传说；不提前描述后期复活或战斗结果。
- [x] 单条 224—242 非空白字，XML样式标签、纯内世界正文，无人物招式清单。

## 分层和剧透说明
- 日之国是在漫画后期正式登场的国度。**关键词绿灯不能单靠专名杜绝提前剧透**；若按前期卷开始游玩，BLUE-08 及本组绿灯在装卡时需设计可切换的阶段门控。
- 此处只写世界既有风俗和通用武道机制；具体的将军、七人众、武道师徒经历和个人技能属于人物/能力层，打败五头龙等事件属于时间线。
- 伍州和广州的建筑街巷、地图和海域细节属于地点层，传说只保留足以让世界自洽的基线信息。
