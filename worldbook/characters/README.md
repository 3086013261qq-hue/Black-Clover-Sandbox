此前 [259项英文实体去重候选](../../sources/003_人物总目录_中英日译名与魔导书初审_v0.1.md) **降为只读查漏备忘**，**不得**以259或239作为必做卡数，也不应将庞大总名单作为逐人审核的前置负担；QA-012保留历史记录，不覆盖主制作方法。

逐位资料足够就直接按已认可的 [人物与能力母版](../../docs/001_黑色四叶草专用人物与能力条目母版_v0.1.md) 写作，不再新增流程或重复优化格式。若有明确缺口，只沿对应人物页面的索引/漫画具体章节做定点核对。
