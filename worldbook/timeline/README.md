## 必须遵守的制卡与日期规范

1. **上/中/下卷彼此绝对独立**：一个世界书条目只装一个完整`<world_timeline>`，每卷A重新起计，日期可以跨卷同日延续，不允许因换卷强制跳天。连续事件仅用A1、A2等子编号。
2. **节省Token但不砍原著骨架**：角色登场、魔导书、装备/法术首次出现、升阶与重大关系转折保留；重复战斗招式说明尽量引用独立能力条目承担，不在时间线重复。
3. **玩家窗口**：只在原著允许的空闲时间保留训练、社交与探索；王都/魔宫/审判日多线战事保持同步，不预设玩家会介入哪条线。
4. **日期**：`1600年MM月DD日`是非官方沙盒日期，需跨卷连续校准；不以漫画现实连载日期代替故事日期。
5. **装配开关**：仅TL-01 v3初始启用，其余24份禁用；输出规则段位置、`@Depth 0`、绿灯`prevent_recursion=true`+`exclude_recursion=true`待装卡实机QA。不使用MVU。
6. **保护层**：8蓝67绿、128人物及128能力原文一律不碰。人物能力层依出现阶段才可用，不能把全成长条目中的后期技能提早暴露。
