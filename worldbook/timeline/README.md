2. **相邻切换时：下一卷事件A日期 >= 上一卷沙盒起始日期 + 1天**。同日连续战役的两份世界书在**沙盒触发日期**上顺延，不意味着原著真实剧情休战、跨夜或人物被强制分流；这条用户最新规则优先于旧v3“跨卷可同日”工程表述。
3. 原著确实存在的**六个月训练、隔年一年三个月、日之国三天准备、战后半年、再隔两年**，不能以“只晚一天”代替，按原本跨度保留。
4. **长度控制**：原v3 TL-06 4093字符拆成v4 TL-06/07（75～90／91～101），原v3 TL-18 4194字符拆成v4 TL-19/20（291～304／305～317）。拆卷时只做事件重编号与独立沙盒，原有人物、能力和事件叙事保持不变。
