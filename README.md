# 《黑色四叶草》原著完整世界书 / 角色卡工程

> Black Clover Sandbox · 咩咩制卡包全栈 · 2026-11-12 启动

## 工程目标

以《黑色四叶草》**漫画全篇**为剧情主依据，整理可供 SillyTavern 互动扮演的完整世界沙盒：设定、人物、能力、时间线、地点，再依照咩咩制卡包·全栈规范装配角色卡。

**当前状态：8条蓝灯与67条绿灯已入库，并完成设定层静态总审及定点优化（QA-011）；人物与能力层尚未生产。设定层仍待原著逐话核对及最终装卡实测，不得声称已通过实机或正式封版。**

## 资料依据

1. 原作漫画及其明确叙述（最高优先级）。
2. Black Clover Wiki 的逐话页面、篇章目录、人物/魔法/组织/地点资料（检索与复核索引，不代替漫画）。
3. 动画与其他官方资料应注明所属媒介；不能无说明混写为漫画正史。
4. 推断与原创须明确标注在工程记录中，不以「原著已有」身份混入正式条目。

查阅入口和首轮篇章索引：[`sources/001_Wiki资料导航.md`](sources/001_Wiki资料导航.md)、[`sources/002_篇章章节索引_初稿.md`](sources/002_篇章章节索引_初稿.md)。

## 工作顺序

设定蓝灯 → 对应绿灯 → 人物 → 能力 → 原著时间线 → 地点 → 世界书构建/装卡 QA → JSON/PNG。

- 人物条目与能力条目分开；特殊状态及装备归属后续按规范核对。
- 时间线按故事实际连续性组织，保留玩家介入空隙，不编造内部年月日。
- 内世界叙述；正式卡中不残留「施工」「Wiki」「原卡」「推测」等外部工作提示。
- 第一卷时间线默认启用的规则在装卡阶段复核。
- 未拿到/核对「咩咩制卡包·全栈」原规范前，不自创正式字段、过滤器、脚本或装配零件。
- 原创玩家角色（包括武道天才构想）与原作事实分离处理，不擅自添加到原著人物目录。
